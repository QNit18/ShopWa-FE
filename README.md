## ShopWa
Đây là trang thương mại điện tử được tạo ra bởi người Việt Nam. Nó bao gồm đầy đủ chức năng từ phía người dùng và quản trị viên. Được viết bằng tiếng Anh, ngoài việc dễ sử dụng cho mọi người, nó còn giúp nâng cao trình độ tiếng Anh của chính lập trình viên.

## Mô hình xây dựng: Spring MVC

## Công nghệ được áp dụng
**Backend**:
+ Spring boot 3.2.0
+ Spring security 6.2.0
+ Hibernate 6.3.1
+ JUnit
+ Restfull Api
  
**Frontend**:
+ JQuery, Fontawesome
+ Themeleaf, Bootstrap 4
  
**Database:**
+ MYSQL 8
**Storage Service**: 
+ Amazon S3
+ Local System

**Cloud platform**:
+ Railway
